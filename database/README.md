# database/

Banco SQLite (`book_book.db`) e scripts SQL usados para criar e popular o banco.

- `ddl.sql` — criação de tabelas, PKs, FKs, CHECK, UNIQUE e demais restrições.
- `dml_inicial.sql` — dados iniciais para demonstrar o sistema.
- `consultas_testes.sql` — consultas de teste e demonstração.
- `book_book.db` — arquivo SQLite gerado a partir do `ddl.sql`.
